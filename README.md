
# 🪐  (guns.lol Clone + Extra Features)

A highly customizable, modern, and animated bio-link website built for creators, gamers, and developers. Think **guns.lol**, but packed with advanced widgets, deeper personalization, and premium fluid animations out of the box.

## ✨ Features

*   **Premium Aesthetic:** Clean, interactive UI with seamless transitions, custom cursor support, and floating animated backgrounds.
*   **Fully Customizable:** Custom HTML/CSS injection, custom domain support, and dynamic themes.
*   **Advanced Widgets:**
    *   **Live Discord Status:** Shows your real-time activity, presence, and status using the Lanyard API.
    *   **Music Presence:** Spotify/YouTube live playback status.
    *   **Interactive Analytics:** Private, lightweight visitor counter and click tracking.
    *   **Crypto Tips:** Integrated wallet addresses for seamless crypto tipping.
*   **Enhanced Security:** Built-in rate limiting and secure input handling to protect against spam bots.
*   **Ultra Lightweight:** Zero bloat, fast load times, and fully responsive across mobile and desktop.

## 🚀 Tech Stack

*   **Frontend:** HTML5, CSS3 (Modern Flexbox/Grid), JavaScript (ES6+)
*   **Animations:** Framer Motion / GSAP (or your preferred animation library)
*   **APIs:** Lanyard API (Discord Presence), Spotify Web API
